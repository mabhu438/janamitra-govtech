# JanaMitra GovTech

Redesign my existing JanaMitra AI website using the uploaded screenshots as references. Give it a premium, modern, professional Indian GovTech SaaS design.

Design:

Deep forest green (#124D3B), sage green (#6E9278), cream (#FAF8F1), white and subtle gold (#D6B36A).

Use Inter and Plus Jakarta Sans fonts.

Clean layouts, modern cards, rounded corners, soft shadows and subtle animations.

Fully responsive on desktop, tablet and mobile.

Improve all existing pages:

Home: Modern hero section with "Government documents, made simple", Telugu subtitle, document upload card, camera capture, drag-and-drop and sample documents.

My Documents: Modern document history, search, filters, previews and document actions.

FeeGuard: Clean fee comparison form with amount difference and percentage results.

Ask JanaMitra: AI chat interface, document selection, suggested questions and document-based answers.

Help: Professional grievance drafting form with evidence checklist and draft generation.

Settings: Language, theme, privacy and accessibility settings.

Additional improvements:

Modern sticky navbar with logo, active navigation, Telugu/English switch and Scan Document CTA.

Attractive feature cards and three-step workflow.

Professional footer and disclaimer.

Smooth hover effects and page transitions.

Proper loading, empty, success and error states.

Important: First inspect the existing project. Modify the current design without rebuilding the project from scratch. Preserve all existing working features, routes, backend integrations and functionality. Do not replace working features with dummy buttons. Keep existing functionality operational.

Focus on visual improvements, consistent styling and better user experience. Do not make unnecessary backend or database changes.
